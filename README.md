# Vocab Quiz

A dictionary search with a daily 10-word multiple-choice vocabulary quiz (646 built-in words). The quiz works offline; looking up new words needs internet. Dictionary data: Free Dictionary API, Datamuse; Hindi suggestions: MyMemory.

- **Android:** download `VocabQuiz.apk` from the [latest release](../../releases/latest) on your phone and open it to install.
- **Laptop (Windows):** open the web app at https://sg9214434100-cloud.github.io/vocab-quiz/ in Edge or Chrome and choose **Install** in the address bar.

Your progress is saved on each device. Use the Backup tab to move it between devices.
